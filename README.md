# Jehovah Jireh Law Firm — Landing Page

A complete, conversion-focused landing page for **Jehovah Jireh Law
Firm**, a personal injury law practice in Srinagar, Kashmir.

Design personality: **authoritative & premium** — deep navy `#0F1E33`
and warm paper `#F8F6F1` in alternating sections, a single muted gold
accent `#B98A2F` (CTAs, key stats, thin rule lines), Libre Caslon Text
serif headlines with Source Sans 3 body text, and engraved symmetry
throughout.

Built for an audience of accident victims who are stressed, skeptical,
and comparing firms — every section works to build trust and remove the
fear of cost: "No fee unless we win" appears at every decision point,
and one CTA ("Free case evaluation") repeats verbatim down the page.

## Details

- One self-contained `index.html` — all CSS inline, no frameworks, no
  JavaScript, no image files (all visuals are CSS gradients and inline
  SVG).
- Semantic HTML, responsive down to 380 px, WCAG-aware contrast,
  `prefers-reduced-motion` respected.
- The code is heavily commented: each design decision is annotated with
  its conversion rationale.
- This page is also part of the six-page
  [landing-pages collection](https://github.com/sadiqmanzoor-1/landing-pages);
  this repository is its standalone home.

## Preview locally

Double-click `index.html`, or serve it:

```bash
python -m http.server 8000
# then open http://localhost:8000
```
